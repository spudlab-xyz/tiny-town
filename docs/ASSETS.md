# Assets and attribution

Every visual, font, sound, or other media asset must have a known origin and terms that allow its use and redistribution in this repository and deployed site.

## Adding an asset

Before committing an asset:

1. Prefer an original project asset or a dependency-free web primitive when it fits the design.
2. Confirm the source and licence. “Found online” and search-result pages are not valid sources.
3. Record the asset name, repository path, creator, canonical source URL, licence name and URL, and any required attribution or modification note in the credits below.
4. Keep a copy of required licence text when its terms require distribution with the asset.
5. Optimise the file without discarding required metadata or attribution, and add a useful text alternative where the asset conveys information.
6. Run the normal checks and confirm the asset loads from the `/tiny-town/` Pages base path.

Do not commit assets with unclear ownership, non-commercial-only terms, incompatible redistribution terms, personal information, or embedded secrets. A contributor must be able to grant the rights described in the pull request; submission alone is not proof of ownership.
